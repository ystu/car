# 保固交接文件 v0.1

**[手機／網頁直接閱讀](https://ystu.github.io/car/)**：含章節目錄、教學圖片、確認回填表與來源索引。

## 先看這三份

1. [保固案件交接手冊](保固案件交接手冊_v0.1.md)：SOP、附件檢查、10 個案例與範本。
2. [確認回填表](確認回填表.md)：由原承辦補實際系統、規則與案件結果。
3. [來源索引](來源索引.md)：回查原始案件、圖片與影片位置，以及哪些內容已檢視。

## 閱讀與修改

- 本機閱讀：用瀏覽器開啟 [HTML 閱讀版](保固交接_閱讀版.html)，圖片已內嵌，可離線閱讀。
- GitHub 閱讀：直接開啟 Markdown 手冊與回填表；HTML 檔案頁會顯示原始碼，需下載後開啟。
- 修改內容：以 `.md` 為主檔，圖片連同 `assets/` 保存。HTML 是靜態閱讀副本，不會隨 Markdown 修改自動更新。
- 原始案件：仍位於 `E:\保固案件`；本資料夾僅有教學所需照片及影片抽樣畫格，不包含完整案件庫。

建議順序：閱讀初稿 → 原承辦回填及修正 → 新人操作演練 → 確認正式版 → 重新產生閱讀版及 PDF。

這一版沒有產生 PDF。需要先列印時可使用瀏覽器列印 HTML；列印分頁尚未做 PDF 視覺校稿。

此儲存庫及網頁目前公開。初稿含案件識別與影像，供原承辦審閱；後續給同事使用的版本及分享範圍另行確認。

## 網頁維護

GitHub Pages 從 main 分支的 docs/ 發布。docs/index.html 是獨立閱讀副本；修改 Markdown 後，需重新產生 HTML，再同步更新 docs/index.html。
