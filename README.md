# 汽車服務廠保固資料

## 保固交接文件

目前為 **v0.1 初稿**，供原承辦檢視、補充實際作業方式與特殊案件經驗。

- **[先讀：保固案件交接手冊](handover/保固案件交接手冊_v0.1.md)**：逐步 SOP、附件檢查表、10 個案例與可複製範本。
- **[原承辦確認回填表](handover/確認回填表.md)**：集中補系統操作、送件規則、期限及案件結果。
- [來源索引](handover/來源索引.md)：原始案件位置及實際檢閱範圍。
- [交接資料使用說明](handover/README.md)：閱讀方式與後續維護。
- [離線 HTML 閱讀版](handover/保固交接_閱讀版.html)：下載後用瀏覽器開啟，含教學圖片與影片抽樣畫格；GitHub 檔案頁顯示的是 HTML 原始碼。

建議閱讀順序：第二章流程 → 第三章 SOP → 第六章特殊案例 → 確認回填表。

Markdown 是可維護主檔；修改並確認內容後，應同步更新閱讀版，再產生正式 PDF。尚未確認的規則與案件結果已在文件中標記。

交接初稿含真實案件識別及影像，先供本機審閱。此儲存庫目前為公開儲存庫，對外上傳前應先處理車牌、車身碼、影像與原始路徑中的案件識別資料。
